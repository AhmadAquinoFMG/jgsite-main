Poppins v24, downloaded from Google Fonts, under the included SIL Open Font
License (OFL.txt). All five existing weights (300–700) and their original
Unicode subsets are retained. Browsers download only the subsets they use.

faces.css is inlined by index.php; its asset URLs are document-relative.
Only the heading (700) and body (400) Latin fonts are preloaded. Font display
remains swap, matching the previous Google Fonts stylesheet.

Source stylesheet:
https://fonts.googleapis.com/css2?family=Poppins:wght@300;400;500;600;700&display=swap

Use a new version directory when replacing fonts because the WOFF2 files
have a one-year immutable cache lifetime.
